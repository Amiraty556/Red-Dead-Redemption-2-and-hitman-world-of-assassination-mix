Arthur Morgan plays HITMAN. This mod installs into Red Dead Redemption 2 (story mode only, single player) and turns each session into a HITMAN-style contract: as Arthur, you get an on-screen contract dossier with the mission name, target name and elimination objective, read live from the player's own HITMAN World of Assassination install (found through Steam's library folders). If HITMAN World of Assassination is not installed, the game says so in-game and uses no substitute content. Solo, story mode only; never touches Red Dead Online. Installed and launched by Melty with one click: Melty installs Ultimate ASI Loader and the mod into the RDR2 folder and starts the game.
